# reduce

## 概要
reduceは冗長なTermやFactorを除去する簡約操作である。
これはパーサで実行するのではなく、インスタンス作成処理内で実行する。
パーサを使わずにオブジェクトを操作した場合にも同様な効果を得るためである。

## 例

### Polynomial
Polynomial内のTermの冗長性を除去する。
```
2 + 3 ➡ 5
x + 5y + 2x ➡ 3x + 5y
x^2 - 3x^2 ➡ -2x^2
3x/y^2 + 2x/y^2 ➡ 5x/y^2
```
#### Termの集約
まずTermの集約キーと値に分割する。
値はTermの係数であり、集約キーは値を除いたものである。
Termの係数は分母と分子のふたつある。
```
2 + 3 ➡ ?
5y ➡ (y, (5,1))
-3x^2 ➡ (x^2, (-3, 1))
3x/2y^2 ➡ (x/y^2, (3/2))
```
